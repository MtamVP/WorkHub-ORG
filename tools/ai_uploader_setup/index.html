AI Auto-Uploader

Phần mềm tự động hóa kết hợp AI (Gemini / ChatGPT) giúp bạn xử lý hàng loạt tài liệu chỉ bằng một click.

v1.0.0 Release

Chào mừng bạn đến với tài liệu hướng dẫn chính thức.

Download Software

Nhận bản phát hành mới nhất. Bao gồm cả Server Core (.exe) và Chrome Extension (.zip).

1. Khởi động Server

Máy chủ là nơi điều khiển các hành động của bạn.

Chạy file thực thi

Sau khi giải nén gói phần mềm đã tải về, hãy truy cập vào thư mục local_server/dist/.

Click đúp vào file AI_Auto_Uploader_Server.exe. Một cửa sổ Terminal màu đen sẽ hiện ra.

Lưu ý: Không tắt cửa sổ này trong suốt quá trình sử dụng phần mềm.

2. Cài đặt Chrome Extension

Extension đóng vai trò là Giao diện điều khiển (UI) và trích xuất dữ liệu.

Cài đặt tiện ích nội bộ

  1. Mở Google Chrome và truy cập địa chỉ: chrome://extensions/
  2. Bật công tắc Developer mode (Chế độ dành cho nhà phát triển) ở góc phải trên cùng.
  3. Bấm nút Load unpacked (Tải tiện ích đã bung).
  4. Trỏ đến thư mục extension của phần mềm vừa giải nén.

3. Cấu hình & Tận hưởng

Thiết lập đường dẫn và các câu lệnh AI (Prompts) để bắt đầu sử dụng.

Quy trình 3 bước

  • Tạo 3 thư mục trên máy (VD: input, output, results).
  • Mở 1 tab Gemini hoặc ChatGPT trên Chrome.
  • Bấm vào biểu tượng Extension ở góc phải Chrome, điền đường dẫn thư mục và chọn Prompt.
Góp ý: Chỉ cần thả 1 file vào thư mục input, quá trình bốc file và gõ phím sẽ tự động diễn ra trong 5 giây!

Dành cho Lập Trình Viên

Nếu bạn muốn chạy trực tiếp từ mã nguồn Python để vọc vạch sửa code, hãy làm theo các bước sau:

Terminal 
cd c:\Users\Admin\Music\WorkFlow_demo\local_server
pip install -r requirements.txt
python server.py

Nếu cài đặt đúng, Terminal sẽ báo "Uvicorn running on http://localhost:8000".
